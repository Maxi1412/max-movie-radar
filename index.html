Checking catalog...

The publishing workflow checks TMDb twice a day after its private API token has been configured in GitHub. Refresh checks the latest published catalog; it does not trigger GitHub Actions.

DVD, Blu-ray and 4K

TMDb release type 5 indicates physical media, which can include DVD, Blu-ray and 4K UHD. The app only includes this release type, but cannot promise that a DVD edition exists. Use the movie link to verify format and local retailer availability.
